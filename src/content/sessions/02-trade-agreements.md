## Before the session

Read the assigned account of isotope-labelling experiments that trace carbon
one way and phosphorus the other. Come with an opinion on whether "exchange
rate" is doing honest work or borrowed prestige.

## In the session

Treat the plant-fungus exchange as a rate that moves, not a fixed gift. What
changes the rate on each side? What would have to be true for one partner to
be described as getting a bad deal?

## Afterwards

The vocabulary from this week — rate, reward, partner, market — recurs
constantly for the rest of semester. Note where it starts to strain.
